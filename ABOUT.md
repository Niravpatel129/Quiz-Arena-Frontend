# About Quiz Arena Frontend

Quiz Arena Frontend is the cross-platform mobile client for Quiz Arena, built with Expo and React Native. It supports trivia gameplay, real-time interactions, push notifications, app-store build workflows, analytics/monitoring, media features, and reusable mobile UI patterns.

For setup and execution, see [`run_instruction.md`](./run_instruction.md). For the broader project overview, see [`README.md`](./README.md).
